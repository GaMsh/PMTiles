pmtiles.ru К карте

О проекте

pmtiles.ru — отечественное зеркало проекта pmtiles.io: формата архива картографических тайлов PMTiles и инструментов вокруг него.

PMTiles придумали в Protomaps: вся пирамида тайлов живёт в одном файле и читается по HTTP Range Request, без своего тайлового сервера. Оригинал спецификации, просмотрщик и документация — на pmtiles.io и в репозитории protomaps/PMTiles.

Что зеркалируем

Мы держим на российских серверах планетарные сборки векторной карты Protomaps (данные OpenStreetMap) и отдаём их с cdn.pmtiles.ru. На главной — полноэкранная карта по этому срезу.

Это независимое зеркало, а не официальный продукт Protomaps. Формат, стиль и исходные сборки остаются проектом авторов PMTiles; здесь — доступ к ним из российской инфраструктуры.

Как подключить

Актуальный срез на CDN: https://cdn.pmtiles.ru/20260915.pmtiles. В MapLibre GL JS: 

import { Protocol } from 'pmtiles';

const protocol = new Protocol();
maplibregl.addProtocol('pmtiles', protocol.tile);

const map = new maplibregl.Map({
  container: 'map',
  style: {
    version: 8,
    sources: {
      protomaps: {
        type: 'vector',
        url: 'pmtiles://https://cdn.pmtiles.ru/20260915.pmtiles',
      },
    },
    layers: [/* стиль Protomaps basemaps */],
  },
});

Запросы к файлу должны идти с заголовком Range. Для сайта на своём домене на CDN нужно разрешить CORS этого Origin (для esya.ru это уже сделано).
